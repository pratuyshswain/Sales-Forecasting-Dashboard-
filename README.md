# Sales Forecasting Dashboard

A retail data engineering demonstration with ETL, a SQLite data warehouse, forecasting and BI-ready exports.

## Documentation and setup

Start with the [project guide](docs/README.md), then consult the [BI connection guide](docs/bi_connection_guide.md) and [schema reference](docs/schema_reference.md).

## Repository layout

- `etl/`: data extraction, transformation and loading.
- `forecasting/`: forecasting components.
- `sql/`: warehouse SQL.
- `exports/`: BI-ready outputs.
- `docs/`: setup and reference documentation.

Use an isolated Python environment and follow the project guide. Back up existing database and export files before rerunning the pipeline. Results are demonstration outputs, not validated business forecasts.
